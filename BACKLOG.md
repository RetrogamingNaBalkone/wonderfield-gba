# Бэклог

## 1.1

- [x] Проверены темы и RNG: повтор номера слова запрещён, повтор темы допустим; восстановлен DOS-расчёт сектора, в сбор времени ввода добавлено отпускание кнопок. Серии быстрого A и ограничения проверки описаны в [отчёте](docs/rng-audit.md).

- [x] Купюры целиком помещаются над нижней панелью с зазором 2 пикселя, включая быстрый пропуск. Название подарка убрано с экрана ведущего перед сертификатом; результат проверен визуально в mGBA.
- [x] Добавлены недостающие подсказки A на экранах ожидания и выбора; убрана подсказка B на первой странице подарка. Портрет опущен на 6 пикселей, счёт человека — на 4. Обрезка барабана подтверждена в исходной DOS-графике и оставлена без изменений.
- [x] Справка сокращена до одного экрана с общими кнопками и командами ввода имени в порядке «пробел / сохранить»; убраны дублирующая строка об отправке слова, лишние нижние подсказки и строка об авторе.
- [x] Меню и справка приведены к серому оформлению окна приза с исходным шрифтом 8×14. Добавлены «Об авторах» в обоих меню и экран GBA-версии с QR-кодом после исходного авторства Димы Башурова. Восстановлен пропуск всех реплик ИИ по A без влияния на случайный выбор.
- [x] L полностью отключает аппаратный звуковой выход на всех экранах; при выключенном звуке слева вверху показан перечёркнутый динамик. Звуковые эффекты продолжают отсчитываться без накопления очереди.
- [x] START открывает единое меню с паузой; рекорды доступны через меню. Заполненное слово отправляется отдельным A, имя сохраняется по START. Короткие итоги продолжаются по согласованным таймаутам; итог раунда, готовые деньги и прощание ждут A.
- [x] Бабблы Якубовича выровнены по правому краю, ширина подстраивается под текст, хвостик закреплён возле ведущего. Баббл поднят к нижней границе строки с буквами, тема при речи не скрывается. Короткие реплики оставляют выпавший сектор видимым.
- [x] Восстановлена непрерывная чёрная обводка бабблов ведущего и соперников.
