# Мультиплеер «Поле чудес» GBA: согласованные правила и UI

Дата фиксации: 10 ноября 2026. Назначение: передача решений в новый чат.
Это спецификация следующего изменения, а не описание уже реализованных режимов.

## 1. Параметры партии

- Три режима: **«По очкам»**, **«По очкам с риском»**, **«По победам»**.
- «По числу побед» в обсуждении обозначает тот же режим «По победам».
- **Классический турнир исключён**. Не добавлять его четвёртым пунктом.
- **Число раундов — независимый параметр: от 1 до 8 включительно.**
- По умолчанию: **«По очкам», 3 раунда**.
- «По победам» означает максимум побед за выбранное число раундов, а НЕ «первый до N побед».
- Словарь, версия персонажей и правило двух шкатулок остаются независимыми от условия победы.
- Новые правила обсуждались для мультиплеера. Изменять правила одиночной игры по этой спецификации не требуется.

## 2. Подсчёт результатов

| Режим | Кто выигрывает партию | Что делает банкрот |
|---|---|---|
| По очкам | Участник с наибольшим общим счётом | Обнуляет заработанное в текущем раунде; завершённые раунды защищены |
| По очкам с риском | Участник с наибольшим общим счётом | Обнуляет весь накопленный счёт |
| По победам | Участник с наибольшим числом выигранных раундов; при равенстве — с большим итоговым счётом | Обнуляет весь накопленный счёт, но НЕ число побед |

- В режиме «По очкам» общий счёт включает текущий раунд. Если всего 450, а в текущем раунде 120, банкрот оставляет 330.
- Перенос текущих очков в защищённую сумму при завершении раунда не должен менять показанное общее число или начислять их дважды.
- В режиме «По победам» сравнивается накопленный счёт всей партии с учётом банкротов, а не только последнего раунда.
- Раунд выигрывает закрывший слово: ответом целиком или открытием последней буквы.
- **Дополнительного бонуса в очках за закрытие слова нет.** Это прямое решение пользователя. Возможность закончить раунд и не дать соперникам заработать — часть стратегии «Поля чудес».
- Если все участники выбыли, не закрыв слово: раунд считается сыгранным, заработанные очки учитываются, победу не получает никто.
- Число раундов здесь означает число основных раундов; перестрелки в него не входят.

## 3. Ничьи и перестрелка

### Два режима по очкам

Если по завершении основных раундов максимальный итоговый счёт одинаков у нескольких участников, проводится перестрелка только между ними. Отстающие не участвуют.

### Режим «По победам»

1. Выбрать участников с максимальным числом побед.
2. Если их несколько, сравнить их итоговые очки.
3. Если и максимальные очки среди них совпали, перестрелку играют только оставшиеся лидеры.

### Правила перестрелки

- Дополнительный раунд на новом слове за победу в партии.
- Побеждает закрывший слово. Очки не используются для повторного определения победителя перестрелки.
- Если все её участники выбыли без разгаданного слова, новое слово и повтор между участниками этой перестрелки.
- Перестрелка не расходует выбранное число основных раундов.
- ИИ участвует на тех же основаниях.
- Совместная победа при перечисленных ничьих не используется.

## 4. Досрочный финиш и первый ход

- В режиме «По победам» партия завершается досрочно, если лидера уже невозможно догнать **даже до равенства побед**.
- Критерий: число побед лидера строго больше числа побед любого соперника плюс число оставшихся основных раундов.
- Если равенство побед ещё возможно, партия продолжается: очки могут решить исход.
- Досрочное завершение для режимов по очкам не согласовывалось.
- **Каждый раунд и перестрелку начинает первый участник из участвующих/оставшихся, в стабильном порядке мест.**
- Чередование стартующего по кругу отвергнуто. Не добавлять его автоматически.
- При перестрелке пропускать места игроков, не вошедших в состав перестрелки. Выбывший в раунде участник не исключается навсегда из всей партии.

## 5. Постоянный ИИ

- В партии с двумя людьми компьютер — один и тот же участник и персонаж от начала до конца.
- Не заменять его после проигранного раунда.
- Не выдавать ему случайные стартовые очки перед стадией.
- Начальный счёт, начисление очков, банкрот, общий результат и победы считать по тем же правилам, что у людей.
- ИИ может выиграть раунд, партию, досрочно обеспечить победу и участвовать в перестрелке.
- При трёх людях ИИ не добавляется.
- Это изменение состава/зачёта не является поручением переписать стратегию выбора букв и решений ИИ.

## 6. Компактная панель GBA

Экран **240×160**. Сохранить существующую нижнюю панель высотой **16 пикселей**, три фиксированные колонки шириной **80 пикселей**. Не строить дополнительную «приборную панель».

- Первая строка: имя игрока, до 10 символов.
- Вторая строка: счёт/счета. Не добавлять третью строку и не сокращать имя ради статистики.
- Позиции игроков в панели стабильны; смена перспективы сцены не переставляет их.
- Реалистичный счёт — до 4 знаков, максимум 5 по оценке пользователя. Это ориентир для верстки, а не разрешение молча ограничить игровой счёт.

| Режим | Строка под именем | Значение |
|---|---|---|
| По очкам | `12345 +1200` | Общий счёт с текущим раундом; справа — очки текущего раунда |
| По очкам с риском | `12345` | Весь накопленный счёт |
| По победам | `12345 П:2` | Очки и число побед |

- Для обычного «По очкам» оба числа важны: второе показывает сумму, которую сейчас можно потерять при банкроте.
- Два пятизначных числа, пробел и знак `+` занимают 72 пикселя при ширине знакоместа 6 пикселей: помещаются в 80.
- `12345 П:2` занимает 54 пикселя; `12345 П:12` — 60.
- Два значения ставить на постоянных позициях: изменение разрядности не должно двигать соседнюю подпись.
- Для «По победам» до уточнения банкрота обсуждались «текущие очки»; последующее явное решение требует накопленного счёта для разрешения ничьей. Показать этот действующий накопленный счёт рядом с `П:N`, чтобы панель соответствовала критериям победы. Отдельное третье число не согласовано.

## 7. Итоги раунда

Последовательность: **завершение раунда → отдельный экран итогов → A → рекламная пауза → следующий раунд**.

- Итоги идут **перед рекламой**.
- Показать победителя раунда либо отсутствие победителя, если все выбыли.
- Показать результаты всех участников, включая ИИ: очки за раунд, общий счёт и/или число побед в зависимости от режима.
- Здесь можно использовать полные подписи, объясняющие компактную игровую панель.
- Для финального/досрочного завершения и перестрелки переход после итогов должен соответствовать состоянию партии, а не безусловно запускать следующий основной раунд.
- Точная верстка экрана итогов пока не нарисована; подобрать её под 240×160, не переносить туда размеры настольного интерфейса.

## 8. Названия раундов

- Историческую лестницу «1/64 финала → … → финал → суперфинал» убрать из новых режимов. При постоянном составе и накопительном зачёте она не отражает структуру партии.
- Обычный раунд: **«Раунд N из M»**, например «Раунд 1 из 3».
- Последний запланированный основной раунд: **«Последний раунд»**. У него нет дополнительных правил или особого веса.
- Дополнительный раунд для разрешения ничьей: **«Перестрелка»**. При повторе название сохраняется.
- «Суперфинал» не использовать и для перестрелки.
- При досрочном завершении режима «По победам» не переименовывать уже сыгранный обычный раунд задним числом в последний: показать завершение партии в итогах.

## 9. Рекорды

**Пока НЕ записывать результаты мультиплеера в таблицу рекордов.**

- Ни очки победителя, ни очки остальных участников, ни результаты ИИ.
- Не создавать сейчас раздельные таблицы по режимам/числу раундов.
- Существующую таблицу одиночной игры и сохранения не повреждать.

## 10. Границы решений

- При реализации пользователь подтвердил сохранение существующего награждения и подарка победителю партии.
- Не задан жёсткий числовой предел счёта или способ отображения более пяти знаков. Проверить арифметику и разумно обработать переполнение ширины; не менять правила незаметным обрезанием числа.
- При реализации пользователь подтвердил: очки перестрелки продолжают общий счёт. Они не решают победу в перестрелке и не записываются в рекорды.
- Счёт «за раунд» на экране итогов при обнулении всей накопленной суммы требует понятного представления потери. Не путать начисленные за раунд очки с изменением общего счёта; конкретная подпись/верстка остаётся задачей UI.

Основные условия победы, ничьи, банкрота, числа раундов, стартующего участника и записи рекордов согласованы. Не возвращаться к отвергнутым предложениям: бонусу за слово, классическому режиму, совместной победе, ротации первого хода или финишу «до трёх побед».

## Уточнения при реализации

- Очки перестрелки продолжают общий счёт партии.
- После итогов партии сохраняются прежнее награждение и подарок победителю.
- В «По очкам» ×2/×4 умножают только очки текущего раунда; в режиме с риском — общий счёт.
