# Передача сборки 2.0beta3

18 ноября 2026 года рабочая сборка получила обозначение `2.0beta3`.
Эта версия указана на титульном экране, в отчёте сборки и в имени
ROM. Для кабельной игры
запишите один и тот же ROM на все консоли. При соединении игра сверяет
отпечаток сборки, в который входит исходник титульного экрана.

В mGBA 0.10.5 прошли все 537 проверок `scripts/verify_v11.py`, включая
попиксельную сверку надписи `2.0beta3` на титульном экране.

При проверке собранный ROM побайтно совпал с копией из коммита
`d26e0ddc223d0e5314418def95e3ae3a420ca5b8`.
SHA-256 сборки — `0f5861d44fa2846ff16a73946f70043de5fe092f8f016adeaad379654f06a2b4`.

## Проверка

Соберите ROM по [инструкции для Linux](../linux-build.md).
Сверьте SHA-256 файла с указанным выше значением для проверенной сборки.

```sh
sha256sum 'dist/pole 2.0beta3.gba'
```
